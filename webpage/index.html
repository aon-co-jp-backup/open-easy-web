特長 / Features

  • ブラウザ(WASM)の管理画面。管理者はメールのワンタイムパスワードで認証。 Browser (WASM) admin UI; the administrator signs in with an e-mail one-time password.
  • 一般の方向けに、操作できない /demo を用意。 A read-only /demo for the public.
  • Linux・Windowsのサーバー、Androidの管理アプリ。 Linux and Windows servers, plus an Android admin app.
